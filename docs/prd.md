## 2. 执行摘要 / 产品概述

**连环计（ChainStrat）** 是一款运行在 Monad 高性能公链上的轻量级在线 1v1 对决游戏。

玩家通过钱包登录后，选择英雄并精心设定技能连招（支持手动顺序设定或自动随机生成），然后与真实对手匹配，进入完全自动的对战播放。对战过程强调策略感与视觉震撼，结果可上链记录，并支持天梯排名。

**核心差异化点**：
- 「先谋后动」的连招设定体验（直接对应成语「连环计」）
- 客户端确定性模拟 + Phaser 4 高品质视觉播放
- 充分利用 Monad 高 TPS、低费用、秒级最终性的优势
- 半日可落地的极简 MVP，同时保留清晰的扩展路径

---

## 3. 背景与问题陈述

当前 Web3 游戏普遍存在以下痛点：
- 实时操作门槛高，普通用户难以参与
- 链上交互频繁导致费用高、延迟明显
- 视觉表现平庸，难以形成「爽感」和传播
- 玩法同质化严重，缺乏策略深度

连环计通过「先设定连招、再观看自动对决」的模式大幅降低操作门槛，同时用客户端高品质动画弥补传统链游视觉不足，并用 Monad 解决性能与费用瓶颈。

## 8. 用户流程

1. 访问 ChainStrat.zhanghe.dev
2. 连接钱包 → 自动 claim 免费英雄（首次）
3. 选择英雄 → 进入连招设定界面
4. 手动点选技能（受 duration 等待 + CD + 60s 录制时钟限制）或使用自动生成
5. 实时预览时间轴 → 开始匹配
6. 匹配成功 → 进入自动对战播放
7. 分出胜负 → 结果上链 → 返回大厅 / 查看天梯

## 9. 核心游戏机制详细说明

### 9.1 连招设定规则
- **手动模式**：强制顺序释放。点击技能后必须等待该技能 duration 结束才能选择下一个；技能进入 CD。录制时钟（含 CD 空等）≤ **60 秒**，技能数量不限。
- **自动模式**：客户端使用种子随机生成合法连招（录制时钟 ≤ 60s，遵守 CD）。
- 实时显示进度条「已用 X.Xs / 60.0s」。
- 详细结算、加时、匹配、上链以 `docs/rules.md` 为准。

### 9.2 战斗规则
- 连续时间模拟（0.05s 步进）
- 支持效果：伤害、眩晕、定身、DoT、护盾、攻击倍率、减伤、吸血、条件爆发（处决）
- 最大战斗时长 60 秒，超时比剩余血量
- 100% 客户端确定性模拟，双方结果完全一致

### 9.3 英雄体系
- 免费英雄 4 个（Warrior / Mage / Assassin / Ranger）
- 付费英雄 3 个（Guardian / Necromancer / Blademaster）作为 Stretch
- 每个英雄 3 个技能，结构统一，方便扩展

## 11. 技术约束与假设

- 使用 **PNPM** 作为唯一包管理器
- 技术栈锁定为 2026 年 8 月最新稳定版：
  - Vite ^8.2 + React ^19.2 + TypeScript ^5.8
  - Tailwind CSS ^4.3
  - wagmi ^3.7 + viem ^2.55 + RainbowKit ^2.2
  - Phaser ^4.2
  - Cloudflare Workers + Durable Objects
  - Monad Foundry + OpenZeppelin v5
- 战斗必须客户端确定性模拟，保证双方结果一致
- 匹配优先使用 Cloudflare Durable Objects，时间不够则降级为机器人
- 所有美术资源由 Grok Imagine 生成
- **半日时间盒为最高优先级约束**
